# تطبيق المسلم | Al-Muslim Web & Mobile App

تطبيق إسلامي شامل ومتقدم مبني وفق معمارية الهواتف الذكية أولاً (Mobile-First Architecture) مع دعم كامل للعمل دون اتصال بالإنترنت (Offline-First PWA). يوفر التطبيق تجربة مستخدم سريعة وخالية تماماً من الرموز التعبيرية التقليدية مع اعتماد نظام أيقونات متجهية SVG موحد ونظيف.

---

## المزايا والخصائص الأساسية

- **مواقيت الصلاة الدقيقة (حساب فلكي محلي):**
  - محرك حساب فلكي مدمج يعمل دون الحاجة لأي اتصال بالإنترنت (محرك PrayTimes).
  - دعم لطرق الحساب العالمية المعتمدة: رابطة العالم الإسلامي، أم القرى (مكة المكرمة)، الهيئة المصرية العامة للمساحة، جامعة العلوم الإسلامية بكراتشي، الاتحاد الإسلامي لأمريكا الشمالية (ISNA)، ومجلس دبي للشؤون الإسلامية.
  - دعم المذهبين الفقهيين: الشافعي/الجمهور والحنفي.
  - عداد تنازلي دقيق ولحظي للصلاة القادمة مع شريط تقدم يوضح الوقت المنقضي بين الصلوات.
  - محدد مدن يدوي يضم أكثر من 38 مدينة إسلامية وعالمية للعمل في حالة تعذر الـ GPS.

- **المصحف الشريف والقارئ الصوتي المدمج:**
  - فهرس متكامل لجميع سور القرآن الكريم (114 سورة) مع بيانات التصنيف (مكية/مدنية) وعدد الآيات ورقم الصفحة.
  - نصوص قرآنية بالرسم العثماني المضبوط لجميع السور مع دعم التخزين المؤقت للعمل دون اتصال.
  - مشغل صوتي مدمج يدعم كبار القراء: الشيخ مشاري العفاسي، الشيخ عبد الباسط عبد الصمد، الشيخ محمود خليل الحصري، الشيخ محمد صديق المنشاوي، والشيخ سعد الغامدي.
  - تكبير وتصغير حجم خط المصحف بسهولة مع حفظ العلامة المرجعية لآخر آية مقروءة للرجوع السريع إليها.
  - شريط أدوات الآية التفاعلي: تشغيل صوتي، نسخ نص الآية، ومشاركتها.

- **موسوعة الأذكار والأدعية (حصن المسلم):**
  - نصوص موثقة ومضبوطة بالشكل مع بيان مصدر الحديث وفضل كل ذكر.
  - تصنيفات متعددة: أذكار الصباح، أذكار المساء، أذكار بعد الصلاة، أذكار النوم، أذكار الاستيقاظ، وأدعية قرآنية ونبوية.
  - أزرار تفاعلية دائرية مزودة بمؤشر تقدم حلقي SVG ينقص تدريجياً مع كل ضغطة حتى اكتمال العدد المطلوب مع تمييز الأذكار المكتملة.

- **المسبحة الإلكترونية الرقمية:**
  - عداد لمس تفاعلي سريع الاستجابة بدائرة نبضية بصرية وتأثيرات موجية.
  - دعم ردود الفعل اللمسية عبر Web Vibration API للأجهزة الداعمة.
  - نقرة صوتية فورية مولدة لحظياً دون تأخير عبر Web Audio API.
  - أهداف تسبيح محددة (33، 100، أو عد حر مفتوح) مع حفظ إجمالي التسبيحات اليومية وتخزينها محلياً.

- **بوصلة القبلة التفاعلية:**
  - حساب جغرافي دقيق لزاوية واتجاه الكعبة المشرفة وفق المعادلات الكروية انطلاقاً من إحداثيات المستخدم الحالية.
  - قراءة حية لمستشعرات التوجيه في الأجهزة الذكية عبر `DeviceOrientationEvent`.
  - حساب المسافة بالكيلومترات إلى مكة المكرمة مع وضع احتياطي إرشادي في حال عدم توفر مستشعر الجيروسكوب.

- **إذاعات القرآن الكريم المباشرة:**
  - بث صوتي حي ومباشر على مدار الساعة لعشر إذاعات وقراء.
  - رسم بياني حي لموجات الصوت مع تحكم كامل بمستوى الصوت وإمكانية كتم الصوت بنقرة واحدة.

- **سجل العبادات وإعدادات التخصيص:**
  - مصفوفة متابعة الصلوات الشهرية (28 يوماً) لمتابعة الالتزام اليومي بالفرائض والسنن.
  - تحديد نية اليوم وحفظها في التخزين المحلي.
  - دعم كامل للوضع المظلم (Dark Mode) والوضع الفاتح مع تناسق لوني زمردي وذهبي.

- **تطبيق ويب تقدمي (PWA):**
  - دعم التثبيت المباشر على الشاشة الرئيسية للهواتف وأجهزة الحاسوب.
  - Service Worker يدعم التخزين المؤقت الكامل لجميع أصول التطبيق، مما يتيح تشغيل التطبيق بالكامل بدون إنترنت.

## البنية المعمارية للمشروع

```text
ALmoslim/
├── css/
│   └── style.css            # نظام التصميم المرئي للهواتف وشاشات الحواسيب
├── js/
│   ├── icons.js             # مكتبة الأيقونات المتجهية SVG
│   ├── prayTimes.js         # محرك الحساب الفلكي الدقيق لمواقيت الصلاة
│   ├── cities.js            # قاعدة بيانات 38 مدينة كبرى للاستخدام اليدوي
│   ├── azkarData.js         # نصوص وأحاديث وأفضال أذكار حصن المسلم
│   ├── surahsData.js        # فهرس 114 سورة والنصوص القرآنية
│   ├── app.js               # المحرك الرئيسي للتطبيق وإدارة المسارات والأصوات
│   ├── home.js              # الصفحة الرئيسية والعد التنازلي للمواقيت
│   ├── quran.js             # المصحف الشريف والمشغل الصوتي
│   ├── azkar.js             # منطق تفاعل الأذكار والعدادات الدائرية
│   ├── tasbih.js            # المسبحة الرقمية، الاهتزاز والصوت
│   ├── qibla.js             # بوصلة القبلة والمستشعرات الحركية
│   ├── live.js              # إذاعات البث المباشر ومحلل الموجات
│   └── settings.js          # سجل العبادات، طرق الحساب، وإدارة المظهر
├── index.html               # واجهة التطبيق الرئيسية أحادية الصفحة (SPA)
├── manifest.json            # معايير تطبيق الويب التقدمي (PWA)
├── sw.js                    # عامل الخدمة للتخزين المؤقت والعمل دون إنترنت
├── service-worker.js        # توافق PWA
├── APP/                     # تطبيق الهاتف المبني بإطار العمل Flutter
├── .gitignore               # استثناء ملفات البيئة والمخلفات المؤقتة
└── README.md                # التوثيق الشامل للمشروع
```

## التشغيل والتطوير المحلي

التطبيق مبني بتقنيات الويب القياسية النقية (HTML5, Vanilla CSS3, Modern JavaScript) دون الحاجة لأي مكتبات أو أدوات بناء معقدة.

### التشغيل عبر خادم محلي:
```bash
# باستخدام Python
python -m http.server 8080

# أو باستخدام Node.js
npx serve .
```

ثم افتح المتصفح على العنوان `http://localhost:8080`.
